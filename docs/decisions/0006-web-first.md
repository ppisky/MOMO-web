## 网页职责

- 保留 React、Mantine/MUI、TanStack Router、品牌、五种语言，以及原角色、对话、分支、篇章和归档行为。
- 当前原网页仍使用已有 Chatbox 业务服务及 IndexedDB 存储，不能称为已接入 MOMO-core。清理 Electron 不等于把 Core 接入也做完；后续按既定契约接替，不额外维护第二份消息状态。
- 浏览器使用标准 fetch、文件选择/下载、剪贴板和 IndexedDB。没有浏览器实现的原生功能明确不支持；不得以空 IPC、假成功或系统 WebView 替代 Electron。
- 模型请求继续只访问用户配置的地址。浏览器遵守供应商 CORS；不添加公共代理、不把凭据转送 Chatbox 服务，也不擅自扩大本机服务监听范围。
- 已停用的本地工具、MCP stdio、技能执行不能因遗留的全局桥接重新启动；不为它们保留 Electron 依赖。

## 已确认的产品规则继续有效

角色卡按 Core 规范区分人物设定、用户设定、版本和作者信息；简介是展示资料，图片是外部资源。角色编辑、记忆和 NSG 各自独立。开场白作为真实首条助手消息保存，参与后续上下文；刷新、重试、重开不得重复插入。

模型参数留空跟随模型，0 是实际数值；参数不冻结到角色/会话，后续使用参数组。Enter 发送、Shift+Enter 换行，组合输入不误发送。记忆存储 Space、注入范围和来源分开；删除对话保留已有资产并停止提取。归档不是删除。

上述规则中原仓库尚未具备的内容仍列为后续功能任务，不在本轮清理时静默改变或登记完成。不恢复旧数据导入兼容需求，也不删除用户已有浏览器数据。

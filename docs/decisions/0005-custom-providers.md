# 0005：纯自定义服务商与五种语言

状态：已实施。日期：2026-10-08。

根据用户要求，撤除预设服务商、服务商兼容配置与全局默认对话模型。服务商页只展示用户添加的自定义记录；添加菜单只有“添加自定义服务商”。API 地址、密钥和模型 ID 由用户填写，不自动把退休的供应商配置转换为新的连接。

保留四种 API 协议适配：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与 Google Gemini。协议名称不代表预装供应商，模型获取只调用填写的地址，不访问 Chatbox 清单或远程模型目录。没有空地址回退、推荐模型或上游推广请求头。旧供应商字段和凭据保留在本地历史数据中但不再提供执行入口；旧对话需要手动选择新的自定义连接。

独立“模型参数”页提供温度、Top P、最大输出 Token 数、上下文消息上限与流式输出。这些参数用于新对话，已有对话保留覆盖值；首页未发送的草稿同步独立参数页的更改。温度和 Top P 的 0 值合法，留空使用 API 默认值。最大输出 Token 数在全局和对话设置中默认显示 0，0 或清空在内部保存为未设置，不向模型调用传入应用层输出上限；正整数保持用户指定的限制。允许省略上限的协议由服务端决定；Anthropic 等要求该字段的协议仍遵循 SDK 的协议默认值，不发送非法的 0。模型 ID 与显示名称在服务商中维护，模型选择属于每段对话。旧 defaultChatModel 偏好载入后清除，不作为模型回退。

只加载并提供简体中文、繁体中文、日语、韩语和英文。MOMO 首页、侧栏、输入区、角色、记忆和新设置页的文案通过五种语言资源统一维护。不支持的历史或系统语言回退为英文。用户角色内容和聊天正文保持原样；上游其他文案继续使用保留语言资源，并非整个上游项目的全面翻译审校。

自动化契约更新到 1.7.7：新参数导航使用 settings-nav-model-parameters，温度和 Top P 沿用原测试 ID，新增 settings-max-tokens、settings-stream。旧默认模型路由仅重定向，不显示默认模型选择器。

未来的桌面运行时与对话内核替换仍为规划。

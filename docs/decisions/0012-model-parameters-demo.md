# 0012：仅模型参数页的离线演示

2026-10-11。用户暂未配置服务商，需要一个只有模型参数页、可以直接操作的演示网站。

- 直接复用正式 `ModelParameters`、对话 JSON、用途 JSON 和原 Web 主题组件，不重画页面，不加入对话、角色或其他设置导航。
- 演示预置文本、视觉和向量化模型，初始对话采样/输出留空、流式开启；后台用途默认折叠，模型选择、参数组、编辑、保存、恢复均可操作。
- 独立入口在 `apps/momo/demos/model-parameters`，独立构建配置只在演示模块图中将 Web 的 API 适配为离线样例。正式入口、API、Core 和用户数据不修改。
- 无需服务商、密钥或 Core。样例参数与当前 Core 契约对齐，但此页面不进行真实请求，不能作为供应商或内核执行验收。
- 修改保存到演示 origin 的本地存储，刷新保留；“重置演示”恢复初始样例。默认端口 1213，与日常网页 1212 隔离。
- 使用既有 pnpm/Vite/React，不增加依赖。提供独立构建和 preview，启动后用实际浏览器核对选择、JSON 同步、保存/刷新及后台恢复。

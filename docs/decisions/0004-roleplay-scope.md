# 0004：以本地角色对话为产品范围

状态：已实施。日期：2026-10-08。

用户要求移除登录、强绑定 Chatbox 网络服务的能力、非角色扮演功能与旧示例对话。继续使用 Electron，保持紫色视觉与双圆标识。

## 当前能力

对话、角色与设置是唯一主导航。保留人物与故事设定、角色头像与背景、本地手动记忆、模型配置、回复重试、分支、新篇章、归档和备份。独立供应商使用 API 配置，本地模型无需账号登录。

## 移除范围

不提供账号登录、设备授权、Chatbox 激活码与订阅、内置云模型、在线角色市场、联网搜索、画图、文档解析、知识库、MCP、技能和工作模式。停用对应入口、启动检查、远程弹窗与主进程后台注册；历史工作模式数据不能恢复工具执行。

共享策略过滤登录供应商并阻断 Chatbox 服务域名。上游未引用的组件、旧路由重定向与数据契约暂留源码，以免破坏旧备份读取与未来合并；这不属于当前产品能力。模型连接已进一步收敛为纯自定义配置，停用远程模型目录预取，见 [0005](0005-custom-providers.md)。

## 旧对话处理

新安装为空列表。首次升级只清理清单中与原始标题、类型、消息 ID 和内容 SHA-256 一致的文本示例。添加消息、改名、修改设定、绑定角色、附件、压缩点、分支与线程均视为用户内容而保留。

删除前备份原始记录到本地键 momo:retired-examples-backup:v1，再移除会话元数据和正文。任何一步失败都不写迁移完成标记；下次启动可继续。备份损坏时停止清理，避免覆盖。该键不作为常规会话展示，也不被自动数据恢复重新加入列表。

此备份不包含在普通会话导出里，需要恢复时先复制数据目录，再通过开发维护工具校验备份并恢复会话和元数据。没有对真实聊天执行批量删除。

## 规划

角色记忆自动提取、角色卡导入格式、桌面运行时与对话内核替换尚未实施。当前版本不提供账号同步或免费模型服务。

# 阶段计划

2026-10-09：回到本仓库，以原页面继续网页开发，移除 Electron，网页调好后再兼容 ron。见 [0006](decisions/0006-web-first.md)。MOMO-app 既有成果保留，不继续两套页面并行开发。

1. 清理 Electron 启动、安装、打包和平台依赖，验证原网页开发及生产入口、角色、请求、流式、刷新和归档。结果见 [验证记录](validation.md)。
2. 按 Core 角色卡契约补齐角色内容与作者等字段。开场白保存为首条真实助手消息并参与上下文，重开/重试不重复插入。页面增加内容时先与用户讨论，已确认语义不重复询问。
3. 对齐模型分类、用途路由和动态参数组；留空继承模型，0 为真实数值。移除快捷键配置，固定 Enter 发送、Shift+Enter 换行，处理 IME。
4. 独立设计和接通空间、记忆与 NSG，区分注入范围和来源归属；删除对话保留资产，删除空间按资产迁移/删除选择处理。
5. 按契约接入 MOMO-core，逐项替换当前 Chatbox 业务服务，避免重复持久化和业务实现。通过真实通路验证后，再恢复 ron 兼容与桌面交付。

后续功能尚未因网页能启动而完成。本轮不恢复安装包/签名/更新渠道，也不新增旧桌面数据导入项目。旧原型计划见 [legacy/ui-prototype/docs](../legacy/ui-prototype/docs)。

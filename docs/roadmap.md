# 阶段计划

按 [0007](decisions/0007-preserve-core-progress.md) 纠正上一轮回退：已移除 Electron，并迁回已有 Core 通路、角色/记忆/NSG、空间、模型与参数组、提示词和固定输入行为。本仓库继续维护网页；App 与 ron 不再并行扩展产品。

1. 当前：保持已恢复能力，验收同一 Core/宿主配置下资产身份一致、模型参数动态生效和聊天终态。不能再次只切到旧 renderer。
2. 按 [产品边界](product-boundaries.md) 补完整角色字段与真实开场白；新增页面布局选择与用户讨论，Core 已定义语义不重问。
3. 补齐记忆/NSG 编辑和生命周期操作、来源与权限/范围投影、带类型方向权重的 NSG 连线。当前只读页不当作完成。
4. 参照保留的原 Chatbox 源码接归档/恢复、分支/篇章等真实 Core 操作，避免空入口或另一套持久化引擎。
5. 网页真实业务稳定后再继续 ron 兼容。安装包、签名、更新和旧格式导入不在当前任务中。

当前验证范围见 [validation](validation.md)，先前原型计划保留在 legacy/ui-prototype。任何缺口都需明确记录，不得用“能启动”替代业务验收。

# 产品边界

| 内容 | 已确认语义与当前边界 |
| --- | --- |
| 角色 | Core 身份稳定；默认助手也是角色。卡片有 name/version/author_name/author_url、character_markdown、user_markdown、opening_markdown。现已支持完整 Core 字段创建/编辑；简介、头像、背景属于应用展示资产。不能把人物设定当简介或丢弃作者。 |
| 开场白 | 作为真实首条助手消息保存并参与上下文；重开/重试不能重复插入。由 Core 原子落库。 |
| 记忆与 NSG | 各自独立页面，也独立于角色编辑。NSG 为 Narrative Semantic Graph，四类有方向、有类型的关系，不能当无语义知识图谱。已接内容/范围编辑、归档恢复和有向边配置。治理候选审批与完整来源审计界面仍待补充。 |
| MO State | 侧栏独立管理页 `/mo-state` 显示当前个人空间的已保存快照、场景/五维约束、输入依据、规则版本及最近 20 次处理；实际注入依该次回复的最终上下文审计。可查询/重置派生角色侧写。配置/继承恢复和状态契约继续在设置，独立于记忆与语义网维护策略。旧记录缺字段如实显示未知，状态生效与快照时间区分。 |
| MOC | 一次选择快速范围，四组快速勾选：角色、对话、记忆与语义网、使用配置；各组可展开细选组件/空间/具体角色，部分选择如实显示。默认不选资产，摘要保持可见。聊天/记忆/NSG 不伪装成逐条选择；兼容格式和密码加密复用 Core。连接、参数组、提示词和界面偏好明确属于全局；空间目录及策略/状态契约按空间选择。密钥不导出；复用宿主扩展模块，导入应用恢复尚未实施。 |
| 三个维度 | 存储归属是 Space；注入范围是角色/会话与 Core RecordPolicy；来源归属是人工/自动及逐修订证据。来源对话不等于注入目标，批准自动产物不改写成手工来源。 |
| 对话删除 | 保留资产，停止待执行和后续提取；不顺带撤销证据或扩大注入范围。UI 生命周期操作仍待接入。 |
| 空间删除 | 默认至少一个，可建/改名/删除；先读取真实资产清点，再让用户选择迁移或删除，可取消。迁移保留资产身份，不根据空查询或失败响应推断没有资产。 |
| 模型 | 顶层仅文本、视觉、向量化；生成用途可以单独指定，未指定跟随对话。向量化不进入生成选择器。协议分类放在服务商/具体模型连接层。上下文长度可空，0 拒绝；视觉用途称视觉回退模型。 |
| 参数组与用途 | 角色和会话不冻结参数；修改组影响后续请求，同一重试请求固定其快照。温度/Top P/最大输出空值继承；0 不代表继承，最大输出必须正整数。对话请求参数 JSON 仅用于对话，额外参数经 Core 允许列表；后台用途直接选符合类型的模型，由 Core 管理用途参数。视觉与向量化入口按已配置类型显示，语义网整理和向量化独立。保存组不暗改实例或其他空间策略。 |
| 提示词 | 通用设置统一管理 Core 的全部提示词空间，区分通用助手、视觉、角色导演、记忆提取、NSG 治理等；其他设置页不重复提示词编辑器。通用助手提示词不影响角色场景。 |
| 输入 | 固定 Enter 发送、Shift+Enter 换行，中文组合输入不发送。取消快捷键配置和 Ctrl+Enter 仅保存。真实对话必须走 Core 和模型。 |
| 界面与对话 | 沿用统一主题和组件。对话归档/恢复由 Core 持久化，侧栏隐藏，设置恢复后使用原身份与历史；资产和自动维护策略不改变。分支/篇章尚未提供。 |
| 数据与仓库 | 不做旧桌面角色/聊天/记忆/图片导入项目；保留现有数据。Core 与 Web 独立，UI 不复制业务内核。 |

## 模型请求与提示词

OpenAI 默认使用 Chat Completions，也可明确使用 Responses 或直接连接 Responses 服务。视觉回退只接受视觉模型；跟随对话仅在对话模型满足视觉类型时可用。语义网整理使用生成模型，语义网向量化使用独立的向量化模型。

向量维数留空时跟随模型默认，不预填固定维数；手动填写与请求 JSON 的 dimensions 双向同步。JSON 仅显示供应商请求参数，不显示内部 profile。Core 校验实际维数，模型或维数变化不能混用旧索引；失败报告降级，不丢弃原资产。

对话请求参数 JSON 直接可编辑；stream 与流式开关及实际请求保持一致。后台用途只有在配置满足类型要求的模型、主动打开编辑器后才能修改请求 JSON。Core 提供推荐值与校验接口，恢复默认删除自定义覆盖，不新增“模型请求空间”。对话 JSON 不传入后台用途。

通用设置包含全部提示词空间，包括记忆提取和语义网维护。独立记忆与语义网设置只包含维护、生命周期等专属策略，避免重复编辑入口。MOC 只导出已修改的提示词；内置正文或已恢复默认的提示词不打包。

## MO State 与归档

闭环自治和状态投影在界面中统一不加版本前缀。MO State 管理展示当前个人空间的最近状态、场景、五维约束、规则版本、输入证据与最多 20 次处理。实际注入按该次完成回复的最终上下文审计，不能用当前配置倒推旧记录。缺失关联显示未知。

管理查询不调用模型、不推进场景；角色侧写重置只清除派生缓存，不修改角色卡与记忆。运行配置、状态契约及恢复继承位于设置，管理页直接链接到设置。

对话归档由 Core 持久化，侧栏隐藏后可在设置恢复；不改变原对话身份、历史、资产注入范围或维护策略。归档与删除是不同操作，归档不能冒充已实现删除。

# 不得因换仓库回退的产品边界

依据此前用户确认与 MOMO-app e664a9007fe523d1c3c24e9ad1edc7ce401e57ef 的产品文档。2026-10-09 迁回原仓库后继续生效；恢复入口不代表未完成业务变为完成。页面布局有新增选择才与用户讨论，Core 已定义的语义先读代码，不反复询问。

| 内容 | 已确认语义与当前边界 |
| --- | --- |
| 角色 | Core 身份稳定；默认助手也是角色。卡片有 name/version/author_name/author_url、character_markdown、user_markdown、opening_markdown。现已支持完整 Core 字段创建/编辑；简介、头像、背景属于应用展示资产。不能把人物设定当简介或丢弃作者。 |
| 开场白 | 必须作为真实首条助手消息保存并参与上下文；重开/重试不能重复插入。已由 Core 原子落库，并验证实际模型上下文；不是待问事项。 |
| 记忆与 NSG | 各自独立页面，也独立于角色编辑。NSG 为 Narrative Semantic Graph，四类有方向、有类型的关系，不能当无语义知识图谱。已接内容/范围编辑、归档恢复和有向边配置。治理候选审批与完整来源审计界面仍待补充。 |
| MO State | 侧栏独立管理页 `/mo-state` 显示当前个人空间的已保存快照、场景/五维约束、输入依据、规则版本及最近 20 次处理；实际注入依该次回复的最终上下文审计。可查询/重置派生角色侧写。配置/继承恢复和状态契约继续在设置，独立于记忆与语义网维护策略。旧记录缺字段如实显示未知，状态生效与快照时间区分，见 [0015](decisions/0015-mo-state-management.md)。 |
| MOC | 一次选择快速范围，四组快速勾选：角色、对话、记忆与语义网、使用配置；各组可展开细选组件/空间/具体角色，部分选择如实显示。默认不选资产，摘要保持可见。聊天/记忆/NSG 不伪装成逐条选择；兼容格式和密码加密复用 Core。连接、参数组、提示词和界面偏好明确属于全局；空间目录及策略/状态契约按空间选择。密钥不导出；复用宿主扩展模块，导入应用恢复尚未实施。 |
| 三个维度 | 存储归属是 Space；注入范围是角色/会话与 Core RecordPolicy；来源归属是人工/自动及逐修订证据。来源对话不等于注入目标，批准自动产物不改写成手工来源。 |
| 对话删除 | 保留资产，停止待执行和后续提取；不顺带撤销证据或扩大注入范围。UI 生命周期操作仍待接入。 |
| 空间删除 | 默认至少一个，可建/改名/删除；先读取真实资产清点，再让用户选择迁移或删除，可取消。迁移保留资产身份，不根据空查询或失败响应推断没有资产。 |
| 模型 | 顶层仅对话、视觉、向量化；生成用途可以单独指定，未指定跟随对话。向量化不进入生成选择器。协议分类放在服务商/具体模型连接层。上下文长度可空，0 拒绝；视觉用途称视觉回退模型。 |
| 参数组与用途 | 角色和会话不冻结参数；修改组影响后续请求，同一重试请求固定其快照。温度/Top P/最大输出空值继承；0 不代表继承，最大输出必须正整数。对话请求参数 JSON 仅用于对话，额外参数经 Core 允许列表；后台用途直接选符合类型的模型，由 Core 管理用途参数。视觉与向量化入口按已配置类型显示，语义网整理和向量化独立，见 [0010](decisions/0010-model-types-and-purposes.md)。保存组不暗改实例或其他空间策略。 |
| 提示词 | 通用设置统一管理 Core 的全部提示词空间，区分通用助手、视觉、角色导演、记忆提取、NSG 治理等；其他设置页不重复提示词编辑器。通用助手提示词不影响角色场景。 |
| 输入 | 固定 Enter 发送、Shift+Enter 换行，中文组合输入不发送。取消快捷键配置和 Ctrl+Enter 仅保存。真实对话必须走 Core 和模型。 |
| 原网页成果 | 保留原主题与组件，不重新设计廉价演示页面。对话归档/恢复由 Core 持久化，侧栏隐藏，设置恢复后使用原身份与历史；资产和自动维护策略不改变。分支/篇章继续补齐，旧业务代码仍保留供对照。 |
| 数据与仓库 | 不做旧桌面角色/聊天/记忆/图片导入项目；保留现有数据。Core、Web、ron 各自独立，UI 不复制业务内核；改动各自 Git 管理。 |

入口恢复见 0007，实际编辑与导出见 [0008](decisions/0008-editable-assets-state-export.md)。来源清单和验证分别见 [0007](decisions/0007-preserve-core-progress.md)、[来源清单](sources/core-ui-restoration.json)、[验证记录](validation.md)。后续不可把表中的“未完成”改写成用户同意取消该功能。

设置显示“个人空间”以区分提示词空间等领域空间。专属自动维护和记忆生命周期位于记忆与语义网，全部提示词在通用设置统一管理；MO State 独立。见 [0009](decisions/0009-settings-and-portable-configuration.md)。

2026-10-10 补充：模型类型显示文本/视觉/向量化，Core chat 枚举不变。MOC 仅导出 source=override 的提示词；恢复默认后排除，内置正文不重复携带。流式开关与对话请求参数 JSON 的 stream 双向同步，实际 Core 请求遵循该值，同一请求 ID 的重试保留原模式。MO State 配置档增加职责解释，保留默认闭环自治与 V1 投影能力；参数页沿用原结构，按 [0010](decisions/0010-model-types-and-purposes.md) 显示对应模型的用途，撤销未确认的折叠布局提案。

后台用途推荐请求配置已按 [0011](decisions/0011-background-request-defaults.md) 实施：Core 提供推荐值与校验接口，配置符合用途的模型后主动就地展开 JSON，支持删除覆盖恢复推荐值。对话 JSON 仍直接显示且与后台独立；向量化只接受自身 profile 配置。覆盖与现有模型用途配置一起保存，MOC 仅携带自定义部分，不新增空间或导出分类。

# 不得因换仓库回退的产品边界

依据此前用户确认与 MOMO-app e664a9007fe523d1c3c24e9ad1edc7ce401e57ef 的产品文档。2026-10-09 迁回原仓库后继续生效；恢复入口不代表未完成业务变为完成。页面布局有新增选择才与用户讨论，Core 已定义的语义先读代码，不反复询问。

| 内容 | 已确认语义与当前边界 |
| --- | --- |
| 角色 | Core 身份稳定；默认助手也是角色。卡片有 name/version/author_name/author_url、character_markdown、user_markdown、opening_markdown。当前基本表单尚未覆盖完整字段；简介、头像、背景属于应用展示资产。不能把人物设定当简介或丢弃作者。 |
| 开场白 | 必须作为真实首条助手消息保存并参与上下文；重开/重试不能重复插入。尚未完成，不再作为待问事项。 |
| 记忆与 NSG | 各自独立页面，也独立于角色编辑。NSG 为 Narrative Semantic Graph，四类有方向、有类型的关系，不能当无语义知识图谱。当前读取页恢复，编辑、治理与完整关系投影未完成。 |
| 三个维度 | 存储归属是 Space；注入范围是角色/会话与 Core RecordPolicy；来源归属是人工/自动及逐修订证据。来源对话不等于注入目标，批准自动产物不改写成手工来源。 |
| 对话删除 | 保留资产，停止待执行和后续提取；不顺带撤销证据或扩大注入范围。UI 生命周期操作仍待接入。 |
| 空间删除 | 默认至少一个，可建/改名/删除；先读取真实资产清点，再让用户选择迁移或删除，可取消。迁移保留资产身份，不根据空查询或失败响应推断没有资产。 |
| 模型 | 顶层仅对话、视觉、向量化；生成用途可以单独指定，未指定跟随对话。向量化不进入生成选择器。协议分类放在服务商/具体模型连接层。 |
| 参数组 | 角色和会话不冻结参数；修改组影响后续请求，同一重试请求固定其快照。温度/Top P/最大输出空值继承；0 不代表继承，最大输出必须正整数。保存组不暗改实例或其他空间策略。 |
| 提示词 | 依 Core 的提示词空间区分通用助手、视觉、角色导演、记忆提取、NSG 治理等；通用助手提示词不影响角色场景。 |
| 输入 | 固定 Enter 发送、Shift+Enter 换行，中文组合输入不发送。取消快捷键配置和 Ctrl+Enter 仅保存。真实对话必须走 Core 和模型。 |
| 原网页成果 | 保留原主题与组件，不重新设计廉价演示页面。归档、分支、篇章等原功能需接到 Core；旧业务代码仍保留供对照，当前 Core 入口的归档仍未接好，不伪造成功。 |
| 数据与仓库 | 不做旧桌面角色/聊天/记忆/图片导入项目；保留现有数据。Core、Web、ron 各自独立，UI 不复制业务内核；改动各自 Git 管理。 |

本轮具体恢复范围、来源清单和验证分别见 [0007](decisions/0007-preserve-core-progress.md)、[来源清单](sources/core-ui-restoration.json)、[验证记录](validation.md)。后续不可把表中的“未完成”改写成用户同意取消该功能。

# UI 与桌面预览：设计及验证

日期：2026-10-08。

## 设计

- 参考 Chatbox 的会话侧栏、顶部会话标题和底部固定输入区，采用独立实现。
- 用户蓝紫图标用于侧栏、欢迎页、回复头像、favicon 与 Windows 应用图标。PNG 保留原图；ICO 由 `scripts/create-icon.ps1` 转换为多尺寸格式。
- 浅紫导航、近白阅读面和紫色操作，深色主题使用深紫灰底色。正文实色，设置遮罩使用轻量模糊。
- 取消旋转、弹跳、位移入场和呼吸效果。按钮只有 100ms 颜色反馈，减少动态效果设置关闭过渡。
- 首屏为真实空状态与四个话题建议，不伪造历史、模型连接或订阅功能。

## 布局与交互

桌面使用双栏、两列话题建议；760px 以下侧栏转为遮罩导航。正文限制宽度，代码块独立横向滚动。设置用原生 dialog；支持 Escape、焦点返回、窄屏导航焦点限制。已适配减少动态、减少透明与强制颜色。

支持消息发送、流式显示、停止、重新生成、复制、会话新建/切换/删除/搜索/重命名。Enter 发送，Shift+Enter 换行，Ctrl/Cmd+K 搜索，Ctrl/Cmd+Shift+O 新建。

## 本轮验证结果

- `pnpm exec node --version`：v26.11.1；系统 Node 未改动。
- `pnpm typecheck`：Web 与桌面严格类型检查通过。
- `pnpm lint`、`pnpm format:check`：通过。
- `pnpm test`：19 项通过。覆盖中文 UTF-8 分块、截断/非法事件、取消、非法/超长消息、完整聊天流、桌面 Cookie/Host/Origin 校验、进程消息及剪贴板参数校验。
- `pnpm build`：Remix 客户端、服务端及 Electron 三入口构建成功。聊天主路由仍有超过 500KB 的 bundle 提示。
- `pnpm package`：生成 Windows x64 asar 便携版，带用户提供的应用图标。
- 浏览器实际操作：建议填入、发送、停止保留部分回复、重新生成、重命名、主题切换、新建、窄屏导航及 Escape。
- 1360×900 桌面和 390×844 窄屏截图检查；深紫会话与浅紫欢迎页均已查看。
- Electron 开发入口及打包后的 `MOMO.exe` 均加载页面，并完成演示回复；开发窗口未记录 renderer error。
- 实际服务测试：无 Cookie 的页面和图标请求均返回 403，打包版未授权页面访问返回 403。
- 开发窗口和打包窗口正常关闭后，相关进程及监听端口均消失；打包版最后一次退出检查为 0 个进程、0 个监听。

浏览器自动化工具向 html 根节点注入 `codex-browser-sidebar-comments-root`，导致 React 18 全文档 hydration 警告；原生 Electron 不包含此注入，未观察到同类错误。没有通过忽略错误或删除工具节点掩盖警告。

本机原生截图接口连续超时，桌面启动与聊天通过可访问界面及进程/网络状态验证；最终视觉截图来自共用同一 UI 的 Web 预览。原生复制按钮的端到端点击未验证，当前只通过参数契约检查；不将此项标为完整验证。

## 当前限制

- 使用本地预设回复，不具备真实智能问答能力。
- 聊天仅在内存中，刷新或退出丢失；删除无撤销。
- 浏览器保存主题；Electron 当前使用临时隔离 session，主题不跨重启保留。
- 尚无 SQLite、凭据设置、附件、语音、工具执行、模型切换或 Markdown 外链跳转。
- 便携版无安装器、签名、自动更新；仅验证当前 Windows x64 机器，未验证干净系统或其他平台。
- CSP 暂为 Remix 引导脚本允许 inline，后续接入 nonce；服务异常通知退出，尚无自动恢复。
- 尚未覆盖 200% 缩放、全部输入法、读屏工具与所有系统辅助功能组合。

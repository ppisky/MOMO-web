## 阶段 1：最小桌面工程

- [x] 确定兼容版本，初始化 pnpm、TypeScript 和构建配置。
- [x] Electron 启动受监管的本地 Remix 服务并加载 React 页面。

## 阶段 2：聊天闭环

- [x] 组合 assistant-ui 界面并接入客户端适配器。
- [x] 使用模拟 Provider 跑通流式响应、停止、失败和重试。
- [ ] 接入一个真实模型提供方及凭据设置流程。
- [ ] 落地 runId、去重、生成状态与取消传播。

验收：发送后流式展示；停止可取消上游请求；失败可恢复；切换会话不会混入响应；页面和日志没有明文凭据；模型输出无法执行脚本。

## 阶段 3：本地历史与设置

- [ ] 实现 SQLite schema、迁移、会话与消息存储。
- [ ] 实现创建、切换、重命名和删除会话。
- [ ] 实现模型连接配置、受保护凭据与非敏感设置。
- [ ] 处理崩溃遗留生成、历史恢复与空状态。

验收：重启后历史与设置可恢复；断网仍可浏览历史；取消/失败的消息状态正确保存；迁移失败不丢弃旧数据；删除操作有明确反馈。

## 阶段 4：交付验证

- [ ] 完成关键路径测试与打包后的手动冒烟。

验收：在不依赖开发机 Node.js 的 Windows 环境运行安装包，完成设置凭据、发送、停止、重启恢复和退出闭环。
